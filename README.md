# Orbit — Personal Command Center

A polished single-page productivity dashboard built with **HTML5, Tailwind CSS and vanilla JavaScript**.

### Features
- Responsive glassmorphism interface
- Persistent task list with localStorage
- Task completion and progress tracking
- 25-minute focus timer
- Live clock
- Theme brightness control
- Zero frameworks or build step
